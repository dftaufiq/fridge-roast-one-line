A small Python program that writes a one-line roast of a smart fridge to /output/entry.txt. The line is fixed and deterministic — the same 155-character line every run: the fridge names the milk Kevin, tracks his mood daily, and texts a six-hour deadline — or he files a complaint.

## Run it

```sh
python3 main.py
```
